# E2 벽 레이어 온톨로지 귀납·벽 탐지 복구 명세

상태: `READY_FOR_AGENT`

근거 사실: 현재 교정 도면에서 `X-평면도(기본형)$0$W1`과 `X-평면도(기본형)$0$W2`는 벽 레이어다. 네이티브 추출은 W1 원형 엔터티 1,672개와 W2 원형 엔터티 1,013개를 읽었지만, 기존 월드 좌표 변환은 배치된 W1 선분 6,094개와 W2 선분 3,742개를 전부 `CLIPPED` 처리해 모델 입력으로 하나도 방출하지 않았다. 따라서 기존 590개 선분·319개 규칙 후보·82개 벽 가설을 이 도면의 실제 벽 탐지 성능으로 해석한 주장은 `RETRACTED`이며, 해당 결과는 관측 경로와 잘못 구성된 모집단의 거동에 관한 증거로만 남긴다.

범위 사실: 여기서 “XCLIP을 제외한다”는 말은 XCLIP을 삭제하거나 XCLIP이 걸린 모든 객체를 비벽으로 처리한다는 뜻이 아니다. 선택한 호스트 DWG와 그 안에 이미 귀속된 콘텐츠만 이번 표적 모집단으로 삼고, 뒤에 연결된 별도 외부 참조 도면은 표적 모집단에서 제외한다는 뜻이다. XCLIP은 표적 여부가 아니라 배치된 객체의 화면 가시 범위를 정하는 표시 제약이며, 호스트에 귀속된 W1/W2가 실제 화면에 보이면 XCLIP 경로를 거쳤더라도 관측되어야 한다.

## Problem Statement

사용자는 CAD 도면에서 벽을 찾아 근거 기반 세계모델을 만드는 시스템을 원한다. 이 시스템은 이미 알려진 회사별 레이어 관습을 실무적으로 활용하면서도, 낯선 이름이나 이름이 제거된 도면에서는 기하와 관계만으로 벽 의미를 복원해야 한다. 또한 시스템은 벽 객체를 분류하는 데서 끝나지 않고 연결된 벽, 문·창 개구부, 폐합된 방과 공간 인접 관계까지 복원해야 한다.

현재 교정 도면에는 W1과 W2라는 실제 벽 레이어가 존재하지만, 기존 변환 경로는 이 표적을 모델 입력에서 전부 제거했다. 전체 선분 보존식은 내부적으로 닫혔으나 의미상 가장 중요한 모집단이 0개가 되었으므로, 단순 총량 보존은 벽 탐지 계측기의 자격을 증명하지 못했다. 그 결과 축·치수·도곽 레이어가 벽 후보의 대부분을 차지했고, 규칙·GBDT·GNN의 결과를 실제 벽 정확도로 해석할 수 없게 되었다.

사람 판정을 완전히 없애면서 동시에 “이 군집이 벽이다”라는 의미를 과학적으로 증명하는 것은 불가능하다. 외부 의미 앵커가 하나도 없으면 어떤 알고리즘도 두 군집의 이름을 `WALL`과 `NON_WALL`로 뒤바꾼 해석을 데이터만으로 배제할 수 없기 때문이다. 따라서 목표는 지상 정답을 없애는 것이 아니라, 새 회사나 새 스타일을 처음 접할 때 소수의 레이어 수준 의미 앵커만 받고 이후 모든 도면에서 객체별 수작업과 실행 중 질문을 0으로 만드는 것이다. 불확실한 경우 시스템은 사람에게 즉석 판정을 강요하거나 임의 라벨을 만들지 않고 `UNKNOWN`으로 기권해야 한다.

W1/W2 정답을 이제 실험자가 알고 있기 때문에 현재 도면은 더 이상 완전히 봉인된 자율 발견 시험지가 아니다. 이 도면은 관측 경로 복구, 레이어 의미 모델 교정, 개입 실험 개발에 사용하는 골든 교정 도면이어야 한다. 다만 `W1/W2는 벽 레이어`라는 사실은 레이어 수준 양성 정답이지, 두 레이어의 모든 엔터티가 벽 본체라는 순도나 이 도면의 모든 벽이 두 레이어에 있다는 완전성을 보장하지 않는다. 시스템이 스스로 벽 레이어를 발견한다는 최종 주장과 객체 수준 AUPRC 주장은 각각 필요한 정답이 예측 동결 뒤에 공개되는 새 도면에서만 허용되어야 한다.

## Solution

하나의 가드된 E2 실험 실행점에서 다음 네 능력을 순서대로 검증한다.

첫째, 벽 레이어 관측 보존을 자격검증한다. 원시 레이어, 블록 정의 레이어, 삽입 레이어, 유효 레이어, 원본 문서 정체성, 블록 배치 경로, XCLIP 판정, 월드 좌표 조각과 모델 입력 ID를 하나의 계보로 연결한다. 각 소스 객체는 `EMITTED`, `PARTIALLY_EMITTED`, `OUT_OF_SCOPE_EXTERNAL_REFERENCE`, `CLIPPED_BY_NATIVE_ORACLE`, `UNSUPPORTED_WITH_REASON` 중 증거가 있는 종결 상태를 가져야 하며, 이유 없는 소실은 0건이어야 한다. W1/W2가 의도된 분석 범위와 네이티브 화면에 존재하는데 모델 입력에서 0개라면 모델 실행을 금지하고 실험을 `BLOCKED`로 종료한다. 내부 보존식과 별도로 AutoCAD가 실제로 표시하는 객체를 독립 오라클로 사용해 XCLIP과 배치 변환을 검증한다.

둘째, 도면별·회사별 레이어 관습을 의미 클래스에 정렬하는 레이어 온톨로지 귀납기를 만든다. 원시 이름은 보존하고 바인드·XREF 접두사는 별도 구조로 분해하여, W1/W2 같은 로컬 이름을 `WALL` 의미에 연결한다. 귀납기는 이름, 색, 선종 같은 관습 신호와 평행쌍, 두께, 연속 사슬, 방 폐합 기여, 문·창 접합, 반복 블록 같은 구조 신호를 분리해 사용한다. 결과에는 의미 클래스뿐 아니라 신뢰도, 적용 범위, 근거, 출처와 채택 상태가 포함되어야 한다.

셋째, 레이어 사전정보와 기하·그래프 모델을 결합해 객체와 공간 구조를 복원한다. 레이어 전용, 이름을 제거한 기하 전용, 두 채널을 분리해 결합한 하이브리드의 세 팔을 같은 모집단에서 비교한다. 규칙은 결정론적 검증기, GBDT는 레이어·객체 집계의 저용량 기준선, GNN은 국소 관계 학습기, Graph Transformer는 방과 반복 평면의 전역 관계 학습기, VecFormer 계열은 자격을 통과한 벡터 시퀀스의 비교 팔, 시각 모델은 렌더 문맥의 보조 배심으로 사용한다. 어떤 모델도 지상 정답을 대신하지 않으며, 기존 CubiCasa 모델 출력은 특징·초기값·비교 기준으로만 사용한다.

넷째, 사람 개입을 운영 경로에서 제거하되 평가 truth와 분리한다. 알려진 회사에서는 동결된 회사별 레이어 온톨로지, 기하 제약, 독립 모델 합의와 의미 보존 개입 안정성을 결합해 자동 판정하고, 실행 중 사용자 질문 수는 0이어야 한다. 증거가 충돌하면 결과를 `UNKNOWN`과 검토 큐로 보내지만 해당 실행을 멈춰 사람 답을 받아 완성하지 않는다. 자동 silver는 학습 후보일 뿐 지상 truth나 봉인 평가 라벨로 승격되지 않는다.

현재 도면은 교정·회귀 fixture로 사용한다. 최종 자율 발견 평가는 새 도면의 정답 레이어를 비공개로 둔 채 예측, 코드, 모델, 설정과 입력 해시를 먼저 동결하고, 그 뒤 정답을 한 번만 공개해 봉인 평가기가 채점한다. 공개 적응 구간에서 반복 개선한 결과를 비공개 시험지에서 세대마다 `keep-if-better`하는 것은 금지한다.

다중 코퍼스 평가는 CubiCasa5K, FloorPlanCAD, ArchCAD를 각각 한 번씩 통째로 제외하는 leave-one-corpus-out(LOCO) 세 폴드로 수행한다. 각 폴드에서는 두 코퍼스로만 학습·선택하고 제외한 코퍼스의 라벨은 봉인 채점기에만 제공한다. 세 폴드의 평균뿐 아니라 각 폴드와 최악 폴드를 모두 보고하며, 코퍼스 3개만으로 전 세계 도면 일반화를 증명했다고 주장하지 않는다.

## User Stories

1. 연구 책임자로서, 나는 의도한 벽 레이어가 모델 입력까지 보존됐는지 알고 싶다, 그래야 잘못된 모집단에서 모델 성능을 주장하지 않을 수 있다.
2. 연구 책임자로서, 나는 W1/W2가 사라지는 최초의 변환 단계를 알고 싶다, 그래야 모델이 아니라 관측 경로를 먼저 고칠 수 있다.
3. 연구 책임자로서, 나는 이전 590개 모집단의 벽 성능 해석이 회수된 상태로 기록되길 원한다, 그래야 후속 연구가 철회된 수치를 기준선으로 재사용하지 않는다.
4. 실험 실행자로서, 나는 원본 DWG를 수정하지 않고 모든 분석을 스테이징 사본에서 실행하고 싶다, 그래야 정본과 실험 산출물을 분리할 수 있다.
5. 실험 실행자로서, 나는 실험 시작 전에 입력 도면과 정답표의 해시를 고정하고 싶다, 그래야 결과 계보를 재현할 수 있다.
6. 실험 실행자로서, 나는 W1/W2가 0개로 방출되면 모델 실행이 자동 중단되길 원한다, 그래야 도구 성공을 실험 성공으로 오인하지 않는다.
7. CAD 계측기 개발자로서, 나는 원시 레이어와 유효 레이어를 따로 보존하고 싶다, 그래야 블록의 `0`·`ByBlock` 상속과 실제 작성 관습을 구분할 수 있다.
8. CAD 계측기 개발자로서, 나는 각 배치 선분이 어떤 블록 정의와 삽입 경로에서 왔는지 추적하고 싶다, 그래야 중첩 블록 오류를 객체 단위로 재현할 수 있다.
9. CAD 계측기 개발자로서, 나는 XCLIP 안팎 판정을 AutoCAD 표시 결과와 교차검증하고 싶다, 그래야 내부 좌표 계산만으로 가시성을 단정하지 않는다.
10. CAD 계측기 개발자로서, 나는 레이어별 원형·배치·가시·방출 수의 보존표를 받고 싶다, 그래야 전체 총량에 가려진 의미 선택적 누락을 발견할 수 있다.
11. 온톨로지 귀납기 개발자로서, 나는 바인드·XREF 접두사를 제거한 로컬 레이어 이름과 원시 이름을 모두 사용하고 싶다, 그래야 관습을 비교하면서 원본 증거를 잃지 않는다.
12. 온톨로지 귀납기 개발자로서, 나는 각 레이어가 벽일 가능성을 순위화하고 싶다, 그래야 W1/W2 같은 벽 레이어를 사람의 전수 판정 없이 제안할 수 있다.
13. 온톨로지 귀납기 개발자로서, 나는 레이어 이름이 보이는 팔과 가려진 팔을 분리하고 싶다, 그래야 이름 지름길과 구조적 벽다움의 기여를 측정할 수 있다.
14. 온톨로지 귀납기 개발자로서, 나는 레이어 의미에 도면·프로젝트·회사 적용 범위를 붙이고 싶다, 그래야 한 파일의 W1 규칙을 전 세계 도면에 과잉 일반화하지 않는다.
15. 온톨로지 귀납기 개발자로서, 나는 제안 규칙마다 증거와 반증 조건을 기록하고 싶다, 그래야 사람이 규칙을 검토하고 철회할 수 있다.
16. 데이터 관리자로서, 나는 W1/W2를 양성으로 기록하되 다른 모든 레이어를 자동 음성으로 만들지 않길 원한다, 그래야 아직 발견되지 않은 벽 유형을 오탐으로 만들지 않는다.
17. 데이터 관리자로서, 나는 레이어 순도와 벽 완전성을 별도로 평가하고 싶다, 그래야 `W1/W2는 벽`과 `모든 벽은 W1/W2`를 혼동하지 않는다.
18. 모델 개발자로서, 나는 레이어 전용 기준선을 갖고 싶다, 그래야 회사 관습만으로 얻는 실용적 상한을 알 수 있다.
19. 모델 개발자로서, 나는 이름을 해시화한 기하 전용 기준선을 갖고 싶다, 그래야 낯선 회사에서도 유지되는 구조 신호를 측정할 수 있다.
20. 모델 개발자로서, 나는 하이브리드 모델이 레이어 사전확률을 기하로 검증하길 원한다, 그래야 유용한 메타데이터를 버리지 않으면서 잘못된 레이어 관습을 맹신하지 않는다.
21. 모델 개발자로서, 나는 기존 CubiCasa GBDT·GNN을 정답이 아니라 비교 기준과 초기값으로 사용하고 싶다, 그래야 알려진 코퍼스 편향이 자기복제되지 않는다.
22. 모델 개발자로서, 나는 규칙·GBDT·GNN·전역 그래프·시각 판정기의 독립성 집단을 표시하고 싶다, 그래야 같은 학습 코퍼스의 동의를 여러 독립 표로 세지 않는다.
23. 평가자로서, 나는 레이어 발견을 Recall@2, Recall@5, 평균 정밀도와 순위 역수로 평가하고 싶다, 그래야 W1/W2를 실제로 상위에 올렸는지 측정할 수 있다.
24. 평가자로서, 나는 객체 판별을 AUPRC, 정밀도, 재현율과 오류 유형으로 평가하고 싶다, 그래야 벽 레이어 발견과 벽 객체 분류를 분리할 수 있다.
25. 평가자로서, 나는 방 폐합률, 면적 오류, 벽 사슬 연결성과 문·창 접합률을 평가하고 싶다, 그래야 선분 점수가 세계모델 품질로 이어지는지 확인할 수 있다.
26. 평가자로서, 나는 회전·평행이동·단위변환·선분 분할·레이어 이름 변경 개입을 재실행하고 싶다, 그래야 의미가 보존되는 표현 변화에 대한 민감도를 측정할 수 있다.
27. 평가자로서, 나는 레이어와 기하의 대응을 무작위화한 대조군을 원한다, 그래야 우연한 레이어 빈도나 클래스 불균형을 학습으로 오인하지 않는다.
28. 평가자로서, 나는 자동 고신뢰 결과에서도 무작위 감사 표본을 받고 싶다, 그래야 자동 silver의 숨은 오류율을 추정할 수 있다.
29. 회사 적응 운영자로서, 나는 한 회사의 소수 지원 도면에서 레이어 관습을 배우고 새 도면에 적용하고 싶다, 그래야 회사마다 모델 전체를 재학습하지 않는다.
30. 회사 적응 운영자로서, 나는 새 도면이 기존 회사 관습과 다르면 분포 이탈 경고를 받고 싶다, 그래야 오래된 W1/W2 매핑을 잘못 재사용하지 않는다.
31. 봉인 평가자로서, 나는 새 도면의 정답을 예측 동결 뒤 한 번만 공개하고 싶다, 그래야 이미 아는 답을 규칙에 넣는 누수를 차단할 수 있다.
32. 봉인 평가자로서, 나는 공개 적응 결과와 비공개 최종 평가 결과가 별도 영수증으로 남길 원한다, 그래야 반복 탐색과 최종 일반화 증거를 구분할 수 있다.
33. 제품 사용자로서, 나는 각 벽 예측에 레이어·기하·그래프·렌더 근거를 함께 받고 싶다, 그래야 결과를 신뢰하거나 반박할 수 있다.
34. 제품 사용자로서, 나는 탐지기가 단일 라벨이 아니라 보정된 확률과 운용점을 제공하길 원한다, 그래야 방 폐합과 수량 산출이 서로 다른 오탐·누락 비용을 선택할 수 있다.
35. 제품 사용자로서, 나는 벽 결과가 방과 공간 인접 그래프로 이어지길 원한다, 그래야 벽 탐지가 더 큰 근거 기반 세계모델의 첫 시금석 역할을 한다.
36. 실험 실행자로서, 나는 “XCLIP 제외”가 외부 참조 도면의 모집단 제외로 적용되길 원한다, 그래야 호스트 도면의 가시 벽까지 함께 버리지 않는다.
37. 실험 실행자로서, 나는 XCLIP이 걸렸다는 이유만으로 객체가 비벽 라벨을 받지 않길 원한다, 그래야 표시 제약과 의미 정답을 혼동하지 않는다.
38. 실험 실행자로서, 나는 각 객체가 호스트·바인드 콘텐츠·외부 참조 중 어디에서 왔는지 알고 싶다, 그래야 분석 범위를 객체 단위로 재현할 수 있다.
39. 데이터 관리자로서, 나는 W1/W2의 양성 레이어 사실과 객체별 벽 정답을 별도 등급으로 보존하고 싶다, 그래야 레이어 이름만으로 모든 객체를 자동 gold로 만들지 않는다.
40. 회사 적응 운영자로서, 나는 알려진 회사의 새 도면을 처리할 때 실행 중 질문을 하나도 받지 않길 원한다, 그래야 다량 도면을 무인 배치로 처리할 수 있다.
41. 회사 적응 운영자로서, 나는 새 관습이 감지되면 시스템이 추측하지 않고 기권하길 원한다, 그래야 사람 0이라는 목표가 조용한 오라벨링으로 변질되지 않는다.
42. 온톨로지 귀납기 개발자로서, 나는 한 코퍼스에서 찾은 anti-wall 술어가 다른 코퍼스에서도 같은 방향인지 확인하고 싶다, 그래야 규칙층이 코퍼스별 오탐을 외우지 않는다.
43. 모델 개발자로서, 나는 VecFormer·GNN·Graph Transformer가 동일하게 자격검증된 객체 모집단을 입력받길 원한다, 그래야 도구 경로 차이를 모델 성능 차이로 오인하지 않는다.
44. 평가자로서, 나는 각 코퍼스를 한 번씩 통째로 제외한 세 결과를 모두 보고 싶다, 그래야 평균이 특정 코퍼스의 붕괴를 감추지 않는다.
45. 평가자로서, 나는 코퍼스가 전이 검정의 통계 단위로 취급되길 원한다, 그래야 도면 수천 장을 독립 도메인 수천 개로 잘못 세지 않는다.
46. 평가자로서, 나는 교차점 밀도와 축정렬을 직접 바꾸는 개입을 원한다, 그래야 그것들이 붕괴의 원인인지 단순 상관인지 구분할 수 있다.
47. 봉인 평가자로서, 나는 평가기가 행 단위 오류나 라벨을 탐색 루프에 돌려주지 않길 원한다, 그래야 점수 조회를 통한 비공개 정답 역추론을 막을 수 있다.
48. 봉인 평가자로서, 나는 최종 시험지가 한 번 열린 뒤 개발 데이터로 강등되길 원한다, 그래야 이미 본 시험지를 다시 봉인 시험지라고 부르지 않는다.
49. 연구 책임자로서, 나는 공개 검증에서만 RSI 규칙을 `keep-if-better`하고 싶다, 그래야 재귀 개선이 비공개 시험지에 적응하지 않는다.
50. 연구 책임자로서, 나는 현재 도면의 레이어 발견 성공과 객체 분류 성공을 별개 상태로 보고 싶다, 그래야 W1/W2를 찾은 사실만으로 객체 AUPRC를 주장하지 않는다.

## Implementation Decisions

- 외부 실행 이음매는 기존 가드된 E2 실험 실행점 하나를 재사용한다. 관측 자격검증, 레이어 귀납, 객체 판별, 개입 시험과 봉인 평가를 그 실행점의 단계로 구성하며 별도의 우회 CLI를 만들지 않는다.
- 벽 실험은 기존 관측 요구인 `nested_insert_world_segments`, `world_lineage`, `silent_drop_detection`, `xclip_preservation`을 모두 선언한다. 이번 범위에 필요한 `source_document_identity`와 `native_display_membership`도 같은 관측 계약에 추가하며, 구현되기 전에는 약한 관측으로 대체하지 않고 `NEEDS_BUILD` 또는 `NEEDS_TOOL`로 닫는다.
- 계측기 상태와 실험 결과 상태를 분리한다. `READY`는 명령을 실행해도 된다는 계측기 허가일 뿐 성능 `PASS`가 아니며, `NEEDS_PROBE`, `NEEDS_TOOL`, `NEEDS_BUILD`, `REDESIGN`, `BLOCKED`에서는 모델 명령이 실행되지 않아야 한다. 실행된 실험의 과학적 판정은 `PASS`, `PARTIAL_PASS`, `PASS_WITH_DEFERRAL`, `BLOCKED`, `RETRACTED`만 사용한다.
- 모든 실험은 원본 도면의 불변성과 스테이징 사본 원칙을 유지한다. 쓰기 작업은 정답 주석을 포함해 파생 사본과 실행 산출물에만 허용한다.
- 관측 계약은 원시 레이어, 정규화 레이어, 유효 레이어, 삽입 레이어, 원형 객체 ID, 배치 객체 ID, 블록 경로, XCLIP 스택, 월드 좌표, 화면 가시성 상태와 모델 입력 ID를 포함한다.
- 분석 범위는 파일명이나 레이어 접두사가 아니라 소스 문서 정체성으로 정한다. 호스트 콘텐츠와 호스트에 귀속된 바인드 콘텐츠는 포함하고, 별도 외부 참조 문서의 객체는 `OUT_OF_SCOPE_EXTERNAL_REFERENCE`로 회계하되 비벽 정답으로 사용하지 않는다.
- XCLIP은 의미 분류기가 아니라 가시성 연산자다. XCLIP 객체나 경계를 삭제하지 않고, 클립 내부·외부 판정은 중첩 블록 변환을 모두 적용한 뒤 네이티브 표시 오라클과 대조한다. 가시 형상이 동일한 두 배치에서 XCLIP 표현만 달라졌다면 모델 입력과 예측은 동일해야 한다.
- 레이어 이름 정규화는 원시 이름을 대체하지 않는다. 바인드·XREF 접두사와 로컬 이름을 구조적으로 분리해 저장하며, 언제든 원시 문자열로 역추적할 수 있어야 한다.
- 현재 도면의 W1/W2는 사용자 확인에서 유래한 `WALL_POSITIVE` 레이어 사실로 기록한다. W1과 W2의 세부 벽 유형은 근거가 없으므로 추론하지 않으며, 다른 레이어는 완전성 검증 전까지 `UNKNOWN`으로 둔다.
- 정답 상태는 `GOLD_LAYER`, `GOLD_OBJECT`, `SILVER_OBJECT`, `POSITIVE_UNLABELED`, `UNKNOWN`을 구분한다. W1/W2 사실은 `GOLD_LAYER`지만 자동으로 `GOLD_OBJECT`를 만들지 않으며, 객체 순도 검증 전에는 W1/W2 객체를 positive-unlabeled 자료로 취급한다. 다른 레이어와 XCLIP 밖 객체는 자동 음성이 아니다.
- 레이어 순도와 벽 완전성은 별도 속성이다. 순도는 W1/W2 내부 객체가 실제 벽인 비율이고, 완전성은 전체 실제 벽 중 W1/W2가 차지하는 비율이다.
- 모델 실행 전 관측 게이트를 둔다. 의도된 분석 범위에 W1/W2가 존재하지만 방출된 모델 입력이 0개이거나 레이어 계보가 끊기면 이후 모델 단계는 실행하지 않는다.
- 소스 객체 수와 배치 선분 수를 1:1로 맞추는 잘못된 보존식은 사용하지 않는다. 하나의 곡선이 여러 조각으로 분할될 수 있으므로 각 소스 객체에서 나온 모든 배치 조각에 계보와 가시·클립·범위외·미지원 처분을 붙이고, 이유 없는 잔여 조각과 이유 없는 소실이 모두 0인지 검사한다.
- XCLIP 판정은 내부 기하 회계 하나로 확정하지 않는다. AutoCAD 표시 결과 또는 동등한 독립 네이티브 오라클과 객체 단위로 대조한 뒤에만 가시·비가시 상태를 확정한다.
- 레이어 발견은 별도 과업이다. 모든 레이어에 대해 벽 의미 점수와 순위를 산출하며, 이름 신호와 기하·관계 신호의 기여를 분리한다.
- 세 개의 필수 모델 팔을 둔다. 레이어 전용 팔은 회사 관습 이용 능력, 이름을 제거한 기하 전용 팔은 관습 불변 신호, 하이브리드 팔은 레이어 사전정보를 구조가 검증하는 실용 성능을 측정한다.
- 레이어 이름 제거는 빈 문자열 하나로 통일하지 않고 충돌 없는 임의 토큰으로 치환한다. 이를 통해 이름 정보만 제거하고 레이어별 그룹 구조는 보존한다.
- 규칙·GBDT·GNN·Graph Transformer·VecFormer·시각 모델의 입력 객체 집합과 분할 영수증은 동일해야 한다. 특정 모델을 실행하기 위해 더 쉽게 추출되는 엔터티만 골라 새 모집단을 만들면 그 팔은 비교에서 제외하고 관측 경로를 다시 자격검증한다.
- 규칙·GBDT·GNN·Graph Transformer·시각 모델은 서로 다른 관측 가족으로 기록한다. 같은 CubiCasa 학습원을 공유하는 모델들은 독립 truth 표로 중복 계산하지 않는다.
- 온톨로지 귀납 결과는 의미 클래스, 신뢰도, 적용 범위, 근거, 반증 조건, 출처, 생성 모델과 채택 상태를 포함한다. 예측 향상만으로 온톨로지 채택을 허용하지 않으며 관계·제약·계보가 없는 단순 문자열 매핑은 로컬 사전으로만 분류한다.
- anti-wall 술어는 공개 학습·검증 구간의 오탐에서만 제안한다. 적어도 두 개의 독립 도메인에서 같은 방향의 효과를 보이고, 의미 보존 개입에서 부호가 유지되며, 이미 취약한 코퍼스의 재현율을 악화시키지 않을 때만 후보 규칙으로 승격한다. 봉인 코퍼스의 오탐을 보고 만든 술어는 해당 코퍼스에 대한 일반화 증거를 무효화한다.
- 사람 개입 0은 “실행 중 질의 0”으로 조작적으로 정의한다. 알려진 회사 도면의 배치 실행은 상호작용 없이 끝나야 하며, 낮은 신뢰도는 자동 추측이 아니라 `UNKNOWN`과 비동기 검토 큐로 남긴다. 새 회사 온보딩의 레이어 수준 의미 앵커와 연구용 무작위 감사는 별도 비용으로 측정하고 객체별 일상 판정과 섞지 않는다.
- 자동 silver 승격은 출처가 독립인 두 증거 가족 이상, 구조 제약 통과, 의미 보존 개입 안정성, 보정된 신뢰도와 분포 이탈 부재를 모두 요구한다. 조건을 통과해도 silver는 gold가 아니며, 같은 silver를 학습 truth와 최종 채점 truth에 동시에 쓰지 않는다.
- 현재 도면은 교정 fixture다. 이 도면에서의 성공은 관측 복구와 재현 가능한 기준선 수립을 의미하며, 자율 발견 일반화의 증거로 사용하지 않는다.
- 회사 적응은 도면·프로젝트 단위 지원 집합과 질의 집합으로 나눈다. 같은 도면의 객체를 무작위로 쪼개 학습과 평가에 나누지 않으며, 새 스타일 적응은 회사별 온톨로지 매핑층을 먼저 갱신하고 모델 전체 재학습은 그 매핑과 저용량 기준선이 실패한 뒤에만 고려한다.
- LOCO는 세 코퍼스 각각을 통째로 제외하는 세 폴드를 모두 실행한다. 학습 코퍼스 안에서만 모델과 규칙을 선택하고, 제외 코퍼스의 라벨 정합표는 봉인 평가기 안에서 점수 계산에만 사용한다. 코퍼스별 라벨 정의가 통일 골든 교집합과 충돌하면 모델 실패와 라벨 불일치를 분리해 보고한다.
- 개입 시험은 두 종류로 나눈다. 회전·평행이동·물리 단위를 보존하는 좌표변환·선분 분할병합·동치 블록 중첩·레이어 이름 치환은 예측 불변성을 요구한다. 교차점 밀도와 축정렬을 벽 의미와 독립적으로 바꾸는 표적 개입, 또는 벽 연결성을 깨면서 아티팩트 통계를 맞춘 반대 개입은 모델이 원인 후보를 실제로 사용하는지 검증한다.
- 모든 개입은 원본 객체와 개입 객체의 대응표, 보존되어야 할 의미, 바뀌어야 할 관측치와 금지된 부작용을 실행 전에 동결한다. 대응표가 깨지거나 의도하지 않은 의미가 바뀐 개입은 모델 실패가 아니라 `INVALID_INTERVENTION`으로 폐기한다.
- 자율 발견은 새 봉인 도면에서 검증한다. 정답 공개 전에 입력, 모델, 코드, 설정, 예측을 동결하고 SHA 계보를 남긴 뒤 비공개 평가를 한 번만 수행한다.
- 공개 적응과 비공개 평가를 분리한다. 비공개 결과를 매 세대 규칙 선택에 재사용하지 않으며, 반복 개선은 공개 구간에서만 허용한다.
- RSI의 `keep-if-better`는 공개 검증 집합에서만 수행한다. 최종 봉인 평가기는 한 번의 동결 제출만 받아 사전등록된 집계 점수와 실패 코드만 반환하고, 행 단위 라벨·오류·특징 귀속을 탐색 루프에 반환하지 않는다. 한 번 공개된 최종 시험지는 즉시 개발 데이터로 강등한다.
- 교정 도면의 레이어 발견 잠정 게이트는 W1/W2 모두 상위 5개 이내, 둘 중 하나 이상 상위 2개 이내, 무작위 레이어 대응 대조군보다 우수함이다. 최종 봉인 게이트와 비용 기준은 봉인 도면을 열기 전에 사전등록한다.
- 객체 수준 성공은 가장 강한 사전등록 기준선 대비 AUPRC와 운용점 성능의 개선으로 판정한다. 같은 도면에서 학습하고 같은 도면에서 채점한 결과는 일반화 증거로 인정하지 않는다.
- 현재 W1/W2 레이어 사실만으로는 음성 정답과 레이어 순도·완전성이 없으므로 전체 객체 AUPRC를 계산하지 않는다. 골든 교집합이 준비되기 전에는 레이어 순위, 알려진 양성의 커버리지, 기권률과 하류 구조 일관성만 보고하며, 전체 객체 AUPRC 상태는 `BLOCKED: LABEL_COMPLETENESS_UNKNOWN`으로 남긴다.
- 최종 제품 출력은 벽 확률에 그치지 않는다. 연결된 벽 사슬, 벽 면 또는 중심선, 문·창 개구부, 방, 공간 인접 관계와 각 결과의 근거 계보를 함께 제공한다.

## Testing Decisions

- 가장 높은 테스트 이음매는 가드된 E2 실험의 외부 실행 결과다. 좋은 테스트는 내부 함수 호출 횟수가 아니라, 실제 네이티브 IR을 입력했을 때 관측 게이트가 잘못된 모집단을 차단하고 완성된 실행 영수증이 계약을 만족하는지를 검증한다.
- 기존 실험 가드, DWG Graph IR 변환, WorldIR 오라클, XCLIP 배선, E2 자격검증과 회사 적응 시험을 선행 사례로 재사용한다.
- 가드 회귀 시험은 필수 관측 하나를 제거할 때 약한 파이프라인을 선택하지 않고 해당 `NEEDS_*` 또는 `BLOCKED` 상태로 종료하며, 모델 명령의 실행 여부가 거짓인지 확인한다. 모든 관측이 실제 프로브와 독립 오라클을 통과한 경우에만 `READY`가 되며, 이 상태 자체는 성능 `PASS`로 집계하지 않는다.
- 현재 도면을 이용한 회귀 시험은 네이티브 원형에서 W1 1,672개와 W2 1,013개가 발견되는지 확인한다. 이 수치는 원형 모집단의 신원 게이트이며, 화면 가시 객체 수나 모델 입력 수와 동일하다고 가정하지 않는다.
- 과거 실패를 고정하는 회귀 시험은 기존 경로가 W1 배치 선분 6,094개와 W2 배치 선분 3,742개를 전부 `CLIPPED` 처리했다는 증거를 재현한다. 수정 후에는 의도된 분석 범위와 독립 표시 오라클에 따라 올바른 가시·비가시 수가 산출되어야 하며, 단순히 전부 방출하도록 바꾸는 것은 합격이 아니다.
- 표적 모집단 수락 기준은 W1/W2 소스 객체 전부가 모델 입력 조각 또는 증거가 있는 비방출 처분으로 추적되고 이유 없는 소실이 0건인 것이다. 독립 표시 오라클이 W1/W2를 하나라도 가시로 판정하면 해당 객체에서 유래한 모델 입력도 하나 이상 존재해야 한다. W1/W2 총 방출 수가 양수라는 사실만으로는 일부 대량 누락을 숨길 수 있으므로 합격하지 않는다.
- XCLIP 범위 시험은 세 장면을 짝지어 검증한다. 호스트의 가시 형상을 유지한 채 XCLIP 표현만 바꾼 동치 장면에서는 동일 객체 예측이 유지되어야 하고, 별도 외부 참조 장면은 `OUT_OF_SCOPE_EXTERNAL_REFERENCE`로 빠지되 음성 라벨이 되어서는 안 되며, 호스트에 귀속된 W1/W2의 클립 안쪽과 바깥쪽은 네이티브 표시 오라클과 객체 단위로 일치해야 한다.
- 레이어 계보 시험은 원시·정규화·유효·삽입 레이어와 객체 ID가 중첩 블록, 미러, 비균일 축척, 배열과 XCLIP에서도 안정적으로 연결되는지를 검증한다.
- 독립 오라클 시험은 모델 입력을 만든 변환 코드와 동일한 판정 함수를 재사용하지 않았음을 영수증에 기록한다. 같은 구현을 두 번 호출한 결과는 합의가 아니라 자기일치이므로 XCLIP 부재·불가능 주장에 사용할 수 없다.
- 이름 제거 시험은 레이어별 그룹 구조와 객체 기하가 동일하고 사람에게 읽히는 이름 정보만 제거됐는지 검증한다.
- 레이어 발견 시험은 이름 허용, 이름 제거, 하이브리드 세 팔이 같은 객체 모집단과 같은 분할을 소비하는지 검증한다.
- 모델 모집단 동등성 시험은 각 팔의 소스 객체 ID 집합, 제외 이유 집합과 분할 해시를 비교한다. 하나라도 다르면 모델 점수를 나란히 비교하지 않고 `BLOCKED: MODEL_POPULATION_MISMATCH`로 종료한다.
- 무작위 대조 시험은 레이어 이름과 기하의 대응을 섞었을 때 성능이 붕괴하는지 검증한다. 무작위화 후에도 같은 성능이면 모델이 진짜 대응을 사용하지 않은 것으로 판정한다.
- 개입 시험은 회전, 평행이동, 물리적으로 일관된 단위변환, 선분 분할·병합, 레이어 이름 변경에서 레이어 순위와 객체 예측의 변화를 측정한다.
- 의미 보존 개입은 객체 대응표가 완전하고 하류 방·개구부 구조가 보존됐음을 먼저 통과해야 한다. 그 뒤 사전등록한 허용 오차 안에서 예측 확률, 레이어 순위와 공간 그래프가 유지되는지를 paired test로 측정하며, 개입 유효성 실패와 모델 불변성 실패를 별도 상태로 보고한다.
- 원인 개입은 축정렬·교차점 밀도 같은 의심 신호를 바꾸면서 벽 연결성과 방 구조를 고정하는 팔과, 의심 신호 분포를 맞춘 채 벽 연결성을 깨는 팔을 함께 둔다. 첫 팔에서 예측이 크게 바뀌고 둘째 팔에서 바뀌지 않으면 모델이 벽 의미보다 아티팩트에 의존한다는 반증으로 판정한다. 단일 특징 제거 후 성능이 유지됐다는 사실만으로 원인이 제거됐다고 결론내리지 않는다.
- 순도 시험은 W1/W2 내부의 객체 유형과 기하를 층화해 벽 본체, 보조선, 심볼, 삽입 객체와 미지원 형상을 분리한다.
- 완전성 시험은 W1/W2 밖에서도 방 폐합과 문·창 접합에 기여하는 벽 후보를 찾아, 다른 벽 레이어가 존재하는지 감사한다.
- 객체 판별 시험은 AUPRC뿐 아니라 정밀도·재현율 곡선, 임계값별 오탐·누락, W1/W2별 오류와 레이어 밖 벽 오류를 보고한다.
- 객체별 음성 gold가 없는 현재 교정 단계에서는 AUPRC 시험을 실행하지 않는다. W1/W2 레이어 검색 순위, 알려진 양성 커버리지, 기권률, 자동 silver 비율과 하류 일관성만 산출하고, full object metric 필드는 null과 `LABEL_COMPLETENESS_UNKNOWN` 근거를 함께 반환해야 한다.
- 하류 시험은 탐지 결과로 방을 폐합하고 방 개수, 폐합률, 면적 오류, 벽 사슬 연결성, 문·창 접합률을 측정한다.
- 자동 silver 시험은 모델 합의와 개입 안정성을 모두 통과한 결과만 후보로 만들고, 무작위 감사 표본의 오류율이 사전등록 상한을 넘으면 승격을 금지한다.
- 무인 운영 시험은 알려진 회사 질의 집합 전체를 비대화식으로 처리하고 `interactive_prompt_count=0`인지 검증한다. 불확실한 객체가 있어도 실행이 즉석 사람 답으로 완성되어서는 안 되며, `UNKNOWN` 수와 검토 큐 비율을 분모와 함께 보고해야 한다.
- anti-wall 규칙 시험은 제안에 사용하지 않은 공개 도메인에서도 효과 부호가 유지되는지, W1/W2 양성 커버리지를 깎아 정밀도만 올린 것은 아닌지, 레이어 대응 무작위화에서도 효과가 남는지를 확인한다. 한 코퍼스에서만 이기는 규칙은 회사·코퍼스 한정 규칙으로 남기고 온톨로지 공리로 승격하지 않는다.
- LOCO 시험은 CubiCasa5K 제외, FloorPlanCAD 제외, ArchCAD 제외의 세 폴드를 빠짐없이 실행한다. 각 결과와 최악 폴드, 코퍼스별 기저율, 라벨 정합 상한을 함께 보고하고, pooled 도면 점수만으로 합격을 선언하지 않는다.
- LOCO의 전이 불확실성 단위는 코퍼스다. 도면 계층 부트스트랩은 각 held-out 코퍼스 안의 표본 오차만 추정하며 코퍼스 3개라는 도메인 불확실성을 없애지 못한다. 보편 일반화 주장은 제4 독립 코퍼스나 새 회사 봉인 집합이 추가될 때까지 `PASS_WITH_DEFERRAL`보다 강하게 말하지 않는다.
- 봉인 시험은 새 도면의 정답을 예측 동결 뒤 한 번만 연다. 봉인 결과를 보고 모델이나 규칙을 수정한 경우 그 도면은 즉시 공개 개발 데이터로 강등하고 새 봉인 도면을 요구한다.
- 봉인 평가기 계약 시험은 입력·정답·평가 코드·지표·분할·제출물 해시가 점수 계산 전에 고정됐는지, 허용 제출 수가 한 번인지, 반환값이 사전등록 집계 지표와 실패 코드만 포함하는지 검사한다. 두 번째 조회, 행 단위 결과 반환 또는 평가 후 임계값 변경이 발생하면 해당 봉인 결과를 `RETRACTED`로 바꾼다.
- RSI 회귀 시험은 후보 생성과 `keep-if-better`가 공개 검증 자료만 읽는지 의존성 추적으로 확인한다. 비공개 라벨, 행 단위 오류 또는 봉인 점수가 규칙 생성·선택 입력으로 흐르면 세대 개선 전체를 `RETRACTED: SEALED_EVALUATOR_REUSED`로 판정한다.
- 모든 PASS는 입력·코드·모델·설정·출력 해시와 분모가 있는 수치를 인용해야 한다. 독립 오라클이 없거나 지원하지 않은 엔터티가 남은 경우 `PARTIAL_PASS` 또는 `PASS_WITH_DEFERRAL`로 제한한다.

다음 실패 코드는 외부 실행 영수증에 안정적으로 남아야 한다.

| 실패 코드 | 발동 조건 | 판정과 허용되는 다음 행동 |
|---|---|---|
| `SOURCE_SCOPE_UNRESOLVED` | 객체가 호스트·바인드 콘텐츠·외부 참조 중 어디에 속하는지 확정하지 못함 | `BLOCKED`; 소스 정체성 관측을 만든 뒤 재자격검증 |
| `TARGET_POPULATION_LOST` | 네이티브 오라클에서 가시인 W1/W2가 모델 입력에서 0이거나 일부가 이유 없이 소실됨 | `BLOCKED`; 모델 실행 금지, 계보·변환 경로 수리 |
| `XCLIP_ORACLE_DISAGREEMENT` | 내부 XCLIP 판정과 독립 네이티브 표시 판정이 객체 단위로 불일치함 | `BLOCKED`; XCLIP 변환·경계 해석 수리 |
| `UNSUPPORTED_TARGET_ENTITY` | W1/W2 또는 하류 폐합에 필요한 형상을 현재 어댑터가 읽지 못함 | 완전성 주장은 `BLOCKED`; 지원 범위를 제외한 탐색 결과만 `PARTIAL_PASS` 가능 |
| `LABEL_COMPLETENESS_UNKNOWN` | 레이어 양성 사실만 있고 객체 음성·순도·완전성 truth가 없음 | 레이어 발견은 계속 가능, 객체 AUPRC와 배포 성능 주장은 `BLOCKED` |
| `MODEL_POPULATION_MISMATCH` | 비교 모델 팔의 객체 집합·제외 이유·분할이 다름 | `BLOCKED`; 같은 모집단으로 재실행 전 모델 순위 금지 |
| `INVALID_INTERVENTION` | 대응표가 깨지거나 보존해야 할 의미·하류 구조가 함께 바뀜 | 개입 팔 무효; 모델 실패로 세지 않고 개입 생성기를 수리 |
| `HUMAN_RUNTIME_QUERY` | 알려진 회사 배치 실행 중 사람이 객체를 판정해야만 완료됨 | 무인 운영 게이트 `BLOCKED`; 기권·큐 경로로 전환 |
| `SILVER_AS_TRUTH` | 모델 산출 silver를 같은 계열의 학습 truth와 최종 평가 truth로 사용함 | 관련 성능 주장 `RETRACTED`; 독립 gold로 재평가 |
| `SEALED_EVALUATOR_REUSED` | 봉인 결과를 보고 후보를 수정하거나 봉인 시험지를 두 번 이상 조회함 | 해당 일반화 주장 `RETRACTED`; 시험지를 개발셋으로 강등하고 새 봉인셋 필요 |

## Out of Scope

- 원본 DWG의 레이어 이름을 변경하거나 정답 주석을 원본에 직접 쓰는 작업.
- 현재 도면의 W1/W2 규칙을 모든 회사와 모든 도면에 보편 법칙으로 승격하는 작업.
- 근거 없이 W1을 외벽, W2를 내벽처럼 세부 유형으로 해석하는 작업.
- W1/W2 밖의 모든 객체를 자동으로 비벽 라벨로 만드는 작업.
- 관측 게이트가 닫히기 전에 새 대형 모델을 학습하거나 기존 모델 성능을 다시 발표하는 작업.
- 하나의 도면에서 학습하고 같은 도면에서 일반화 성능을 주장하는 작업.
- 모델이 만든 silver label을 지상 정답으로 사용하거나 같은 silver로 학습과 채점을 동시에 수행하는 작업.
- 현재 명세만으로 다중 회사·다중 코퍼스 일반화를 완료했다고 주장하는 작업.
- 동결된 Ariadne 기관을 재가동하거나 이 실험을 위해 별도 제어 평면을 만드는 작업.
- 데이터셋·모델·엔진을 새로 다운로드하거나 원본 CAD 자산을 이동·삭제하는 작업.

## Further Notes

- W1/W2를 아는 것은 실험을 끝낸 것이 아니라 표적 누락을 발견할 오라클이 생긴 것이다. 현재 가장 먼저 풀 문제는 모델 선택이 아니라 W1/W2가 실제 화면 범위에서 모델 입력까지 보존되는지다.
- 레이어 이름은 실무에서 합법적인 센서다. 다만 관습 불변 의미 능력과 회사별 관습 활용 능력을 한 점수로 합치지 말고 이름 허용·제거·하이브리드 팔로 분리해야 한다.
- W1/W2 사실은 우선 현재 도면에 한정된 양성 지식이다. 다른 도면에서 반복 확인되면 프로젝트, 회사 순으로 적용 범위를 승격하고, 반례가 나타나면 좁혀야 한다.
- 기존 CubiCasa 전이 붕괴 결과는 다중 코퍼스·회사 적응 설계를 계속 정당화하지만, 현재 도면의 이전 82개 가설 결과는 실제 W1/W2 벽 성능 증거가 아니다.
- 온톨로지 귀납의 성공은 예측 점수 하나로 정의하지 않는다. 의미 개념, 관계, 제약, 적용 범위, 반증 조건, 출처, 채택 규칙과 봉인 일반화 증거가 함께 있어야 한다.
